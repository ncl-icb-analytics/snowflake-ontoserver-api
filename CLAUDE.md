# Claude Development Settings

## Commit Messages
- Use conventional commits format
- Do not include Claude signatures or co-authorship in commits
- Keep commit messages concise and descriptive

Example commit format:
```
feat: add comprehensive usage examples for ECL queries
fix: update OAuth placeholders to be more descriptive
docs: update README with references to usage examples
```

## Repository Standards
- Remove sensitive information (specific role names, credentials)
- Use generic placeholders like 'your-client-id-here'
- Include comprehensive documentation and examples
